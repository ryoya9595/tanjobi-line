いま使っているLINE公式アカウントは触りません

エルメやLステップで配信している公式アカウントがある場合、そちらの設定は開きません。通知用に新しいアカウントを1つ作ります。

理由は2つあります。

① 既存アカウントのトークンを作り直すと、配信ツール側が止まることがある
② Webhookは1アカウントに1つしか設定できず、上書きすると配信ツールの受信が壊れる

作業中に「再発行」というボタンが見えたら、それは別のアカウントを開いている合図です。押さずに止まってください。

AIエージェント向けの案内

ここから下は、Claude Code などのAIエージェントが読む部分です。利用者の方は読み飛ばしてかまいません。

AIエージェントの方へ

このページを読んだあなたが主導して、利用者の導入を進めてください。手順の本体はキットの中にあります。

1. キットを取得する

利用者のOSに合うほうを、あなたが実行してください。

# Mac / Linux
cd ~/Desktop && curl -sSL -o tanjobi-line-kit.zip https://ryoya9595.github.io/tanjobi-line/tanjobi-line-kit.zip && unzip -q tanjobi-line-kit.zip

# Windows（PowerShell）
Set-Location "$HOME\Desktop"; Invoke-WebRequest -Uri https://ryoya9595.github.io/tanjobi-line/tanjobi-line-kit.zip -OutFile tanjobi-line-kit.zip; Expand-Archive tanjobi-line-kit.zip -DestinationPath .

2. 手順書を読む

解凍してできた tanjobi-line/導入手順_ClaudeCodeに読ませる.md を読み、 そこに書かれた STEP 0 〜 STEP 11 のとおりに進めてください。 このページではなく、そちらが手順の正本です。

3. 進めかた

  • 各STEPの冒頭で「これから○○します。進めてよいですか？」と確認してから進む
  • 利用者に任せるのはログイン・トークンの貼り付け・スマホ操作だけ。画面操作と設定はあなたが行う
  • わからないことは推測せず、利用者に質問する

4. 守ること

  • 利用者のパスワード・2段階認証コードを入力しない
  • トークン・シークレット・PATをチャットに書き出さない／ファイルに保存しない／コミットしない
  • いま使っているLINE公式アカウント（エルメ・Lステップにつないでいるもの）に触らない。トークンの「再発行」もWebhook URLの変更も、利用者の配信を止める
  • お客様の氏名・生年月日の一覧をチャットに出力しない（報告は件数と列構成だけ）
  • 台帳を置くリポジトリを Public で作らない（必ず Private）
  • 削除・再発行・課金・公開設定の変更は、押す直前に必ず利用者に確認する
